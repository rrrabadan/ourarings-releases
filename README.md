# Oura Ring S+ · Releases

Instaladores Windows do **Oura Ring S+**, cliente local para o anel Oura Gen 3 (Windows 11).

- **Baixar**: na release mais recente, `Oura.Ring.S+_<versão>_x64-setup.exe` (Intel/AMD) ou `_arm64-setup.exe` (ARM). O MSI x64 é alternativo.
- **Atualizações**: o app instalado verifica este repositório ao abrir e a cada 6 h e avisa quando há versão nova. Os instaladores são assinados; o app só instala pacotes com assinatura válida.
- O código-fonte fica em repositório privado; este repositório contém apenas os binários publicados pelo CI.
